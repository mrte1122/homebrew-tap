# mrte1122/homebrew-tap

Homebrew casks for apps by [@mrte1122](https://github.com/mrte1122).

```bash
brew install --cask mrte1122/tap/quotacat
brew install --cask mrte1122/tap/steamwatch
```

| Cask | App |
|---|---|
| `quotacat` | [Quotacat](https://github.com/mrte1122/Quotacat): GitHub API limits, Actions minutes, Copilot usage, pull requests and failing workflows in the macOS menu bar |
| `steamwatch` | [Steamwatch](https://github.com/mrte1122/Steamwatch): Steam wishlist sales, target prices, new lows, playtime and friends online in the macOS menu bar |

Both apps update themselves, so `brew upgrade` isn't needed; the casks are bumped on every release anyway.
